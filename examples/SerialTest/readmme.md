# SerialTest

Simple send/receive example for TaniDLL.

---

## ▶ What It Does

* Opens COM port
* Sends "HELLO"
* Receives response
* Displays result

---

## 🚀 Usage

Run:

```vba
Sub TestSerial()
```

---

## ⚙️ Configuration

Update:

```vba
COM5
115200
```

---

## 💡 Notes

* Requires a connected serial device
* Must match baud rate
