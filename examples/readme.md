## 📊 Advanced Demo

### 👉 RealTimeExcelLogger

Real-time data logging from multiple ESP32 devices into Excel.

* Supports multiple COM ports (e.g. COM5, COM17)
* Continuous data reception and visualization
* Excel chart updates in real-time
* Ring buffer implementation (20 samples loop)

📈 Perfect for:

- Sensor monitoring
- IoT prototyping
- Real-time data visualization
- Excel-based dashboards

💡 This example demonstrates how Excel can function as a real-time monitoring tool using TaniDLL.
