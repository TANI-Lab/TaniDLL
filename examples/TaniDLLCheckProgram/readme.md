# TaniDLL Check Program

This example provides a full automatic test for TaniDLL using ESP32.

---

## 🔌 Setup

1. Open `TaniDLL.ino.ino` in Arduino IDE
2. Upload to ESP32
3. Connect via USB

---

## ▶ Run Test

In Excel VBA:

* Run `TaniDLL_AutoTest`

---

## ✅ What is Tested

* Text communication
* Binary communication
* Terminator handling
* Timeout behavior
* Buffer limits
* Continuous communication
* Error handling

---

## 🎯 Expected Result

All tests should display:

```
[PASS]
```

---

## 💡 Notes

* Baud rate: 115200
* Make sure COM port matches your environment
